# MCData standards and acceptance

Traceability from the supplied specifications to MCData Phase 1 increments. Each
row names the procedure, the acceptance evidence required before it is claimed,
and its status. Status values: **Planned**, **Blocked** (reason given), **Done**
(with a link to its test document).
